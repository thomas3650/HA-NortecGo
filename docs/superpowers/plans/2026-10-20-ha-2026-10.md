# Move the dev environment to Home Assistant 2026.10 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. In this repo the flow in `docs/way-of-working.md` §1–2 applies (implementer and task-reviewer agents, waves, worktrees).

**Goal:** the gates pass on Home Assistant 2026.10.2 with #117's dev versions, and the integration declares
2026.10.2 as its minimum (#119, #55).

**Architecture:** one task and one commit. Taking #117's `pyproject.toml` and `uv.lock` breaks mypy in two
places, so the lock, the two typing fixes, the minimum version, the notes and the changelog land together,
and the commit passes the gates.

**Tech Stack:** Python 3.14, Home Assistant 2026.10.2, `probatio`, mypy `--strict`, ruff, uv.

**Spec:** `docs/superpowers/specs/2026-10-20-ha-2026-10-design.md` (issue #119). Read it with the task: this
plan argues from it.

## Global Constraints

- **Behaviour is unchanged.** No entity, option, flow step, text or log line changes, and nothing near
  charge start or stop. `config_flow.py` changes only its schema import and the `vol.` prefixes.
- **The lock is #117's, byte for byte.** `pyproject.toml` and `uv.lock` come from commit
  `24ecc2055868637211f58cdd9b95dd6eb25be9eb`. Don't run `uv lock` with an upgrade.
- **Tests:** only the import line in `tests/test_binary_sensor.py` changes. If any other test fails, stop
  and report it.
- **Only these files change:**
  - `pyproject.toml`, `uv.lock`;
  - `custom_components/nortec_go/config_flow.py`, `custom_components/nortec_go/binary_sensor.py`;
  - `tests/test_binary_sensor.py`;
  - `hacs.json`, `.github/ISSUE_TEMPLATE/bug.yml`;
  - `docs/ha-notes.md`, `CHANGELOG.md`.

  Not `version` in `manifest.json`: the controller runs the bump step.
- **Gates before the commit** (`CLAUDE.md` → Commands):
  - `uv run pytest -q`;
  - then `uv run ruff check && uv run ruff format --check && uv run mypy && uv run actionlint && uv run zizmor --offline .github/workflows`;
  - then `uv run pytest --cov=custom_components.nortec_go --cov-report=term-missing --cov-fail-under=95`.
- **Where:** in the main checkout (`<checkout>`; the dispatch gives its path), on branch `fix/ha-dev-bump`.
  Edit files by absolute path.
- **Commit message:** written with the Write tool to `/tmp/ha-2026-10-task-1-msg.txt`, and committed with
  `git commit -F <file>`. No heredocs. End it with the co-author trailer from the dispatch.
- **Nothing private** (hard rule 3).
