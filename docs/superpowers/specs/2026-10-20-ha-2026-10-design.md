# Move the dev environment to Home Assistant 2026.10 — design

Date: 2026-10-20 · Branch: `fix/ha-dev-bump` · Issue: #119 (also closes #55)

## Goal

- **What:** take Dependabot's #117 dev bumps, fix what they break, and raise the Home Assistant minimum:
  - `pytest-homeassistant-custom-component` 0.13.367 → 0.13.373, which brings Home Assistant 2026.10.2;
  - ruff 0.16.9 → 0.17.1, mypy 2.3.1 → 2.4.0, pre-commit 4.6.2 → 4.7.0, zizmor 1.30.1 → 1.31.1;
  - `hacs.json`'s `homeassistant` minimum, 2026.9.3 → 2026.10.2 (`releasing.md` → *Bumping Home Assistant*).
- **Why:** #117 fails `lint`, with five mypy errors against Home Assistant 2026.10. The new lock also clears
  the Dependabot alerts that #55 tracks: `cryptography` 48.0.1 → 50.0.1 and PyJWT 2.13.0 → 2.15.1, which is
  outside every open PyJWT alert's range. aiohttp 3.14.3 → 3.14.5 also clears its three alerts, which aren't
  part of #55.
- **Not in this work:** any behaviour change in the integration. No entity, option, flow step or text
  changes, and nothing near charge start or stop. Dependabot's other PR, #115, is separate.
- **Done when:**
  - the gates pass on Home Assistant 2026.10.2;
  - `scripts/smoke` passes;
  - `hacs.json` says 2026.10.2;
  - `CHANGELOG.md` has the entry below;
  - `docs/ha-notes.md` no longer says the flow API wants voluptuous;
  - the bump step has run (0.6.2), and the PR says `Closes #119` and `Closes #55`.
